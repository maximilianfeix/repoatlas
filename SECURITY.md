# Security Policy

## Supported versions

Only the latest `v2.x` release receives security fixes. Update to the latest v2 release before reporting an issue against an older version.

## Reporting a vulnerability

Use the **Report a vulnerability** button on the [RepoAtlas Security Advisories page](https://github.com/maximilianfeix/repoatlas/security/advisories) to send a private report. Do not disclose suspected vulnerabilities in public issues, pull requests, or discussions.

Include the affected RepoAtlas version, Node.js version, operating system, impact, and steps to reproduce. Avoid including credentials, private source code, or other sensitive data unless it is necessary to demonstrate the issue.

The maintainer will review private reports, coordinate a fix with the reporter, and agree on a responsible disclosure. Response and remediation times depend on the report and its severity; no fixed response-time guarantee is offered.

## Scope

Security reports may cover the RepoAtlas CLI, browser analyzer and map, GitHub Action, MCP server, and published package. RepoAtlas analyzes repository source statically and does not execute analyzed project code.
